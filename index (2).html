Colortoons + ColorArt Pipeline

Colortoons is the React Native color-by-number mobile game. ColorArt is the FastAPI backend powering it — MiniBatchKMeans quantization → OpenCV segmentation → Pole of Inaccessibility labeling → Chaikin/Catmull-Rom SVG smoothing.

Converts any image into an interactive SVG color-by-number map without heavy AI models. Fast, reliable, and low resource usage.
